# RemoteGuard 1.0.0

Stable release of the server-side request admission library. MIT; no external dependencies. Install RemoteGuardRoblox.lua as RemoteGuard; optional RemoteGuardServer.lua as its sibling RemoteGuardServer. QuickTest model is for a blank Studio place only. Select Test > Debug Error > On Unhandled Exceptions, then Play (F5).

Evidence: 29 core and 8 adapter suites at O0/O1/O2, 39 selected behavioral mutations detected, independent finite models, 982,275 external numerical checks on rc.2 (including repeated observations and oracle checks), and maintainer-reported 24/24 Studio checks with actual client-server calls. Only VERSION declarations changed in runtime code. Historical audit hashes remain tied to rc.2.

Not an anti-cheat, network firewall, distributed quota or transaction manager. Multi-client load and actual player departure during a live remote invocation remain unverified. See README, SECURITY.md and docs/API.md.
