# Verification
Run `lua5.4 tests/regression.lua`, `lua5.4 tests/adapter.lua`, `lua5.4 tests/bootstrap.lua`, and `luau tests/regression.lua` from the root. Pure modules intentionally use portable Lua syntax. Run `lua5.4 tests/policy_examples.lua` or `luau tests/policy_examples.lua` for hand-written English, Spanish and Portuguese fixtures. The deliberately small fixture set documents exact matches and limitations; it is not a real-world safety or accuracy benchmark. The adapter runs against a Lua mock, not Roblox Studio. CI uses checksum-pinned Luau 0.734 and compiles every shipped server/client source. Compilation checks syntax, not Roblox engine behavior. Run `python3 tests/mutation.py` with Lua 5.4 installed to test selected deliberate regressions in temporary copies. The suite rejects survivors and does not count syntax errors as detections. This is a targeted diagnostic, not a complete mutation-coverage claim. The regression suite also exhaustively enumerates length-five traces over a nine-operation alphabet for three small admission configurations and compares each decision/reason to a scan-based reference. It compares generated phrase dictionaries to a simple token-sequence oracle. These are bounded tests, not universal proofs. The benchmark is comparative, using source snapshots from specific Git commits generated by the workflow; it checks decision checksums and reports median-of-three timings without brittle performance thresholds.

[Optional Studio-only smoke script](studio/README.md) provides an isolated native test channel and aggregate callback counters. It has not been executed in Roblox Studio; CI only compiles it.

Studio / live experience checklist (not yet executed):
1. Remove old ChatMessage RemoteEvent and all legacy scripts that send or display player text. Leave native chat enabled.
2. Test the default native-only configuration with PlatformIntegratedChat enabled. Verify reporting, mute/block, chat restrictions and no custom player-text path.
3. If testing legacy_text, explicitly confirm platform-integrated chat is disabled in Studio, select that mode, and use a channel whose delivery callback is owned exclusively by ChatFilter. Test two or more clients, recipient-specific privacy and text variants, blocked content, sender self-echo, rapid messages, joining/leaving, direct and folder-parented late-created channels, and rejection of reserved channels. Also separately test context mode with integrated chat enabled; do not ship it unless callback and native permissions work as documented. Test two players in the same gameplay group and a third in a different group, then change/remove membership during play. Check that native permissions still apply even within a matching group.
4. Confirm native text filtering still applies to every delivery. Confirm a blocked message is not seen by other players; the sender may see local echo per Roblox documentation.
5. Compare against representative benign conversations in English, Spanish and Portuguese before changing lists or enabling fuzzy matching.
6. Do not use this package to circumvent future API restrictions. Disable the legacy hook before switching to platform-integrated chat.
