# Integration rules

Read README.md, docs/API.md, docs/SCHEMAS.md and SECURITY.md. RemoteGuardRoblox.lua is the core; optional RemoteGuardServer.lua requires sibling ModuleScript RemoteGuard. Server owns subject and action identity. Pass full `...` (do not truncate extra args). Global is per subject; Server is optional shared quota. Invalid payloads/permissions consume quotas. Schema rules are bounded and closed; no coercion. Instance rules need Class and server-owned Ancestor. Do not trust client prices, ownership, privileges or positions. Check only for synchronous actions; action MaxInFlight requires Begin/Release. Never release work that might still run. Forget invalidates old generation but retains occupied shared slots until release. After yields use IsCurrent and revalidate domain state before commit. Adapter Wrap does not bind; caller owns callbacks. It returns true + handler returns, false + generic code. Sweep from owner loop to reap dead threads, not suspended ones. Destroy does not cancel arbitrary application work. No raw logs, cross-server limits, network firewall, production or formal-verification claims.
